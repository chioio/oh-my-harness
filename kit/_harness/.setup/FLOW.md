# Setup Flow

## 目标

将 setup 后的本地私有层补成一个可工作的项目级 harness。

## 流程

1. 先确认当前项目是开发型、数据汇总型，或混合型项目
2. 了解当前项目的主要工作流与确认边界
3. 了解当前项目的重要目录、受保护区域与技术栈偏好
4. 明确长期 memory 和短期 memory 的边界
5. 按最小必要原则生成本地 `_harness/` 核心文件
6. 完成后移除或替换补充占位

## 约束

- 不跳过用户对话
- 不在信息不足时直接生成完整规则
- 优先生成最小必要的 `_harness/` 结构
- 保持共享入口与本地私有增强层分离
